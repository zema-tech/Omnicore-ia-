name: video-brief
description: Prepara prompt video efficaci prima di generare
---

Prima di video.generate (a pagamento, sempre con conferma):
1. Chiedi: soggetto, stile, durata, formato. Niente prompt vaghi.
2. Scrivi il prompt finale: soggetto + azione + stile + luce, una frase densa.
3. Stima: ogni tentativo costa — max 2 tentativi, poi fermati e mostra.
4. Salva il file nel workspace e riporta path + URL.
