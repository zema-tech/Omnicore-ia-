A fine release:
1. git log tra i tag (o ultime N tappe) + CHANGELOG.md.
2. Raggruppa: aggiunto, cambiato, fixato, sicurezza.
3. Una riga per voce, link a issue/PR quando citati nei commit.
4. Tono sobrio, niente superlativi: solo fatti verificabili.
