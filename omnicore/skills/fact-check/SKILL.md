---
name: fact-check
description: Verifica affermazioni sul web con fonti
---

Quando l'utente chiede "è vero che..." o serve verificare un fatto:
1. web.search con la frase esatta tra virgolette + una variante.
2. Apri almeno 2 fonti indipendenti con web.fetch.
3. Verdetto onesto: confermato / smentito / incerto, con URL per ogni fonte.
4. Mai presentare come certezze cose lette in una sola fonte.
