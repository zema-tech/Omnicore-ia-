A fine settimana, su richiesta:
1. Sessioni recenti (presence/sessions) + git log della settimana.
2. Estrai: fatto, bloccato, imparato (dalla memoria attiva).
3. Scrivi nota in vault con [[settimana]] e 3 action per la prossima.
4. Max una pagina: densità, non romanzo.
