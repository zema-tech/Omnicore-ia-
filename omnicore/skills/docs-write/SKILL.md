Quando serve documentare:
1. Leggi il codice vero (code.read/symbols), non inventare API.
2. Struttura: scopo in 2 righe, esempi copiabili, variabili env in tabella.
3. Aggiorna CHANGELOG.md con voce per tappa e docs/STUDIO.md se cambia la roadmap.
4. Verifica link e path citati (esistono davvero nel repo?).
