name: inbox-zero
description: Svuota la inbox IMAP in una passata
---

Quando l'utente chiede inbox zero:
1. email.read unseen limit 20: mappa tutto prima di toccare niente.
2. Per ognuna: rispondi (bozza + conferma), archivia mentalmente, o ignora.
3. Mai segnare lette a mano dal tool (PEEK di default): la lettura resta pulita.
4. Report finale: quante, quante urgenti, cosa aspetta risposta tua.
